\chapter*{Abstract}

This dissertation explores the process of taking a Legacy system,
which is a system that relies on depreciated technology,
and making it compatible with more modern technologies.
Some of the considerations taken include:
ensuring the new system performs the same functions to the same or a higher degree,
making sure the actions that the user takes are the same or similar to the original,
% include one more point
As well as modernising the system this dissertation also suggests and demonstrates
additional features to further improve the user experience of the system,
such as various algorithms for providing search recommendations.
This will make the system much more accessible to newer users who have less experience with the original system,
and possibly improve certain workflows the existing users already take.
